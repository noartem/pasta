🍝 Pasta

The tastiest note manager on the entire internet. Paste or type anything, save it and share the link.

Versions

A pasta is never changed in place. Saving an edited pasta creates a new version with its own link, so every shared link keeps showing exactly what was shared. Versions form a tree: the panel in the bottom right corner links to the previous and next versions and to the whole tree.

Anyone with a link can see the whole version tree, including later edits, and save new versions of it.

Keyboard shortcuts

Ctrl+EnterSave
Ctrl+[Previous version (add Alt to open it in a new tab)
Ctrl+]Next version (add Alt to open it in a new tab)
Ctrl+ClickOpen a link
Alt+WSwitch between the full-width and the centered editor
Alt+LChoose the syntax highlighting language (Esc or Enter returns to the text)

On macOS use Cmd instead of Ctrl, and Ctrl+Option instead of Alt (Ctrl+Option+W, Ctrl+Option+L).

In the lists of pastas and versions:

↓ / j, ↑ / kSelect the next / previous pasta
Home / EndSelect the first / last pasta
Enter / oOpen the selected pasta (Alt+Enter: in a new tab)
← / →Previous / next page
/Search (Esc leaves the search field, ↓ goes to the results)
nCreate a new pasta

Syntax highlighting

The kind of text is detected automatically: plain text, Markdown, CSV (each column in its own color), JSON, YAML, HTML, CSS, JavaScript, TypeScript, Python, PHP, Rust, Go, Java, C/C++, Shell and SQL.

If the guess is wrong, pick the language in the bottom right corner (or press Alt+L). The choice is saved with the pasta; "Auto" goes back to detection.
